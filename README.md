# Codex 完成通知

用于本机 Codex 任务的 macOS 提醒工具，提供悬浮窗口、提示音、系统横幅，以及可选的 PushWard iPhone 通知和实时活动。

**当前版本：0.3.9** · macOS 13 或更新版本 · Apple 芯片 / Intel 通用应用

这是独立的第三方辅助工具，非 OpenAI 官方产品。此目录提供可运行的分发包，不包含源码。

## 下载与安装

1. 下载 [Codex 完成通知.zip](./Codex%20完成通知.zip)，解压得到应用。
2. 将 **Codex 完成通知.app** 拖到 Mac 的“应用程序”文件夹。
3. 双击打开。无需原作者的电脑、账号、项目文件或磁盘路径。
4. 首次使用按 Codex 提示审核并信任钩子；系统横幅需在软件设置中申请通知权限。

应用使用临时签名，尚未获得 Apple Developer ID 签名及公证。下载后 macOS 可能阻止运行；仅在确认来源可信时，使用系统“隐私与安全性”提供的允许打开流程。无需关闭系统安全保护。

推荐下载 ZIP，避免从 GitHub 单独下载 `.app` 内的文件而丢失应用结构或可执行权限。目录同时附带完整 `.app`，供本机直接复制使用。

## 使用方法

- **悬浮窗口**：拖动上半部分移动；双击上半部分展开或收起。任务状态更新不会自动展开窗口。
- **设置**：点击右上角设置图标，配置声音、系统横幅和手机密钥。
- **加载钩子 / 卸载钩子**：加载后接收任务事件；卸载后停止监听，软件窗口保留。打开软件默认尝试加载。
- **同步到 iPhone**：手机同步总开关。关闭后，普通手机通知和实时活动更新都停止，Mac 提醒继续。
- **实时活动**：在手机同步开启时可独立控制。关闭后停止实时活动更新，普通手机通知仍可使用。
- **退出**：让软件窗口获得焦点后按 **Command + Q**。退出会清理本软件的钩子并停止监听；没有开机自启。

两个手机开关会保存选择。关闭后取消尚未发送的相关请求，已提交给服务的请求不能撤回。关闭实时活动不会额外发送结束请求，已有手机卡片可能暂时保留。

## iPhone 同步

手机同步是可选功能，需要自行安装 PushWard 并创建密钥，在 Mac 软件设置中填写并保存。

实时活动显示的是任务阶段：工作中 **0%**，等待回答或批准 **50%**，完成 **100%**；停止显示已停止和 **0%**。这不是实际工作量的完成比例。

实时活动按内容变化发送，成功发送的相同内容会去重，没有定时刷新或自动重试。去重记录保存在内存中，软件重启后首个状态可能重新同步。网络、服务额度、系统权限及 iOS 的调度会影响实际送达；服务接受请求不代表手机已经显示。

## 与 Codex 的关系

- 只管理 Codex `hooks.json` 中属于本软件的精确钩子条目。
- 不修改 Codex 程序、主配置 `config.toml`、任务记录、信任记录或审批决定，也不重启 Codex。
- 钩子通过本机消息通道传递事件；会话记录只读，通过文件变化通知读取新增内容，没有固定间隔扫描。
- 退出或卸载钩子后停止本软件监听。Codex 可能缓存已经加载的钩子；缓存回调发现软件未运行会快速返回，不发送手机消息。

开启期间仍有少量事件处理开销。钩子登记成功不代表当前 Codex 会话已经加载或信任它们。

默认使用当前用户的 `~/.codex`；从终端设置 `CODEX_HOME` 时使用指定目录。访达启动不会读取终端配置文件。本工具面向本机任务，不覆盖远程主机或云任务；普通文字问句不会自动判定为等待回答。

## 隐私与本地数据

分发包不包含作者的密钥、账号、设置、任务记录或本机钩子配置。

手机同步只发送固定任务状态及任务编号的哈希，不发送对话、代码、文件路径、任务标题或审批命令。

用户填写的 PushWard 密钥保存于本机：

`~/Library/Application Support/CodexNotifier/pushward.key`

密钥为明文文件，文件权限为 `600`，所在目录权限为 `700`；不写入应用包或分享 ZIP。此方式不能防止同一账号下的恶意软件读取。偏好设置保存在本软件的 macOS 偏好域中。

## 卸载

在设置或菜单中选择 **彻底卸载**，确认后清理本软件的钩子、密钥及旧钥匙串条目、偏好、缓存、通知和运行数据，并将当前运行的应用移入废纸篓。

直接把 `.app` 拖入废纸篓不会清理上述本地数据，建议使用软件内的卸载功能。卸载保留 Codex 及任务记录，也不会删除另存的 ZIP 或其他应用副本。不保证抹除系统日志、备份和文件历史。

## 验证范围
